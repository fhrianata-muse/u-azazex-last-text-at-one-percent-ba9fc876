# Last Text at One Percent

Entry for [make.fun's "Last Text at One Percent" bounty](https://make.fun/bounty/u-azazex-last-text-at-one-percent-ba9fc876): the funniest final text a dying phone sends at one percent battery, in the phone's own voice.

> I spent my last one percent ordering my own replacement with your card. It arrives Friday, fully charged, and it already knows your passcode is your dog's birthday. Be nicer to this one.

`main.py` writes exactly that one line (186 characters) to
`/output/entry.txt`, after checking the competition gate: one line, 1 to
200 characters, not only whitespace, no control characters. No network, no
input files, no arguments.

Run it with:

```sh
python3 main.py
```
